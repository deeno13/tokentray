# TokenTray
<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop with Tauri and WebView2.

## Stack

Rust, Tauri 2, and plain HTML/CSS/JavaScript. Reuse the MIT CodeNotch Windows implementation where practical.

## Users and purpose

Show AI-tool usage from a compact Windows tray popup inspired by CodeNotch.

## Capabilities and constraints

Eight providers are supported: Claude Code, Codex, Cursor, Antigravity, GLM, Grok, OpenCode Go, and GitHub Copilot. The repository is public and MIT-licensed. Credentials stay in native adapters. Quotas and derived activity counts must remain distinct; missing data is unavailable.

## Brand commitments

Use CodeNotch's compact usage presentation with Windows Acrylic.

## Future scope

Code signing, an installer, automatic updates, multi-account support, and activity hooks. Distribution is currently through unsigned portable GitHub releases.
