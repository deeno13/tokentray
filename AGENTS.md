# TokenTray

Windows tray app: Rust / Tauri 2, local HTML/CSS/JavaScript, WebView2. Keep provider credentials in Rust and never log, persist, or return them to JavaScript. Reuse existing sessions read-only. Missing quota is unavailable, never zero. Never add agent turns, reset-credit redemption, automatic credential refresh, or provider configuration edits to monitoring.

Run `cargo test`, `cargo build --release`, and `node --test tests/*.test.mjs`. Windows CI is the native build gate. Preserve third-party attribution. Keep provider parsing separately testable with synthetic fixtures. Manual refresh must honor cooldowns. Do not deploy or publish a public release without authorization.
